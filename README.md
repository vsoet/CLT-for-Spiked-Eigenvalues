# MS-PCA outlier fluctuation CLTs

The main manuscript is `MS-PCA_outlier_fluctuation_CLTs.tex`; its compiled
version is `MS-PCA_outlier_fluctuation_CLTs.pdf`.

- `code/` contains the reproducible Monte Carlo experiment and recorded data.
- `figures/` contains the Q-Q figure included by the manuscript.
- `lean-formalization/` contains the machine-checked algebraic and probabilistic
  implications, together with a precise account of the external random-matrix
  inputs that remain outside the formalization.
- `references/` contains the locally retained papers used most heavily for the
  fluctuation and local-law arguments.
